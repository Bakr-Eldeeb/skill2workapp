# تشغيل Skill2Work — نسخة V4

فك الملف وافتح PowerShell داخل `skill2work-angular` بجوار `package.json`.

استخدم Node 24.15 أو أحدث ضمن الإصدار 24، أو Node 22.22.3 أو أحدث ضمن الإصدار 22.

```powershell
npm ci
npm start
```

افتح http://localhost:4200/ . إذا كان المنفذ مشغولًا، أوقف خادم Angular السابق أو استخدم `npx ng serve --port 4201`.

الحسابات الأساسية: `candidate@skill2work.demo` و`company@skill2work.demo` و`university@skill2work.demo` و`admin@skill2work.demo`. كلمة المرور للاختبار فقط: `Demo123!`. تفاصيل إضافية في DEMO_ACCOUNTS.md.

النسخة تطور V3 وتضم ملفات المرشح والشركة والجامعة، معرض مشاريع، متطلبات المهارات بالحد الأدنى بدل الأوزان، وتذاكر QR للمعارض. شروط الترشيح لا تمنع التقديم. الدرجة العامة للمسار المهني تحتفظ بأهمية المهارات الخاصة بالنظام.

البيانات وتذاكر التسجيل والصور محفوظة في هذا المتصفح فقط؛ لا توجد قاعدة بيانات مشتركة بين الأجهزة. تسجيل الدخول محلي وليس آمنًا للإنتاج. نتائج التقييم تدريبية بقواعد محلية وليست تقييم ذكاء اصطناعي حقيقيًا أو شهادة. التفاصيل في صفحة «عن التقنية» وAPI_INTEGRATION.md.

الصور JPG/PNG/WebP حتى ٥ ميجابايت، تُصغّر وتُحفظ في IndexedDB مع بديل محدود الحجم. يستخدم مسؤولو التوظيف المسجلون نفس ملف المرشح للقراءة فقط بما فيه بيانات التواصل؛ استخدم بيانات اختبار ولا تضع معلومات شخصية حقيقية. تحليلات الجامعة مجمعة فقط.

تذكرة المعرض تعرض QR حقيقيًا برمز عشوائي دون بيانات شخصية داخله. تدعم التنزيل والطباعة وقائمة تذاكر الجامعة. ليست تصريح دخول آمنًا ولا توجد ميزة مسح أو تسجيل حضور. تغيير الجامعة يلغي التسجيلات السابقة.

النشر على GitHub Pages مجهز للمستودع `skill2work` بمسار `/skill2work/` وروابط hash. لم ننشر هذه النسخة أو نعدل مستودعك العام. راجع GITHUB_PAGES_AR.md بعد اعتماد التصميم.
